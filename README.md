# system_mon

**PC 의 CPU, 메모리, GPU, 디스크, 네트워크 사용량과 그것을 많이 쓰는 프로그램을 글자로 보여준다.**

PC 가 무거울 때 무엇이 먹고 있는지 한눈에 보려고 만들었다. 띄워 두면 2초마다 화면을 고친다.

```
CPU 49% ████████░░░░░░░░   메모리 21.3 / 32.0 GB (67%)
GPU NVIDIA GeForce RTX 3090 53% ████████░░░░░░░░   VRAM 2.8 / 24.0 GB
디스크  읽기 1.2 MB/s  쓰기 410 KB/s    네트워크  받기 3.1 MB/s  보내기 200 KB/s

프로그램                         개수  CPU(한 코어)     메모리
browser                            23          120%     3.9 GB
editor                              4           70%     2.1 GB
game                                1           34%     1.4 GB
```

## 시작하기

Python 3.9 이상이 필요하다. Windows 에서 만들고 시험했다.

```bash
git clone https://github.com/destory1984/system_mon.git
cd system_mon
pip install -r requirements.txt
python sysmon.py
```

끌 때는 Ctrl+C.

## 옵션

| 옵션 | 하는 일 |
|---|---|
| `--interval 5` | 5초마다 고친다 (기본 2초, 가장 짧게 0.5초) |
| `--sort mem` | 메모리 많이 쓰는 차례로 (기본은 CPU 차례) |
| `--top 30` | 프로그램을 30줄 보인다 (기본 15줄) |
| `--once` | 한 번 재고 꾸밈 없는 글로 찍고 끝낸다. 파일로 받거나 붙여 넣을 때 쓴다 |
| `--no-gpu` | GPU 를 재지 않는다 |

## 가장 단출하게: cpu.py

CPU 사용량만 10초마다 한 줄씩 찍는다. 화면을 지우지 않고 아래로 쌓인다.

```bash
python cpu.py        # 10초마다
python cpu.py 5      # 5초마다
```

```
17:07:55  CPU  48%
17:08:05  CPU  52%
17:08:15  CPU  47%
```

값은 그 10초 동안 모든 코어의 평균이다.

## 숫자 읽는 법

- **맨 윗줄 CPU** 는 모든 코어를 합친 사용률이다. 6코어 PC 에서 50% 면 코어 3개를 쓰는 것이다.
- **프로그램의 CPU** 는 한 코어 기준이다. 120% 면 코어 1.2개를 쓰는 것이다.
- **같은 이름의 프로그램은 하나로 묶어 더한다.** 브라우저처럼 프로세스가 수십 개인 것도 한 줄이다. 「개수」가 묶인 프로세스 수다.
- **메모리** 는 Windows 작업 관리자와 같은 값(개인 작업 집합)이다.
- **GPU** 는 NVIDIA 그래픽카드만 보인다 (`nvidia-smi` 로 읽는다). 없으면 그 줄이 빠진다.

## 얼마나 가벼운가

프로세스 480개가 떠 있는 6코어 PC 에서 2초 간격으로 띄워 뒀을 때 한 코어의 0.8%, 메모리 37MB 를 썼다.

Windows 에서는 프로세스를 하나씩 열지 않고 운영체제에 한 번만 물어 모두 받는다.
하나씩 여는 방식은 같은 PC 에서 한 번 재는 데 20초가 걸렸고, 지금 방식은 0.03초다.
